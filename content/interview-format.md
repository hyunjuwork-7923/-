# D매거진 인터뷰 기사 · 준비 문서

**대상**: 서울 채집가방 / 그레이쥬스
**상태**: 인터뷰 미실시. 이 문서는 질문지와 기사 뼈대다.
**원칙**: 없는 말을 만들지 않는다. 답변 자리는 비워 둔다.

---

## 1. 인터뷰 포맷이 맞는 이유

레퍼런스로 본 edit.dept 게시물의 주력 문체가 Q&A였다. 에세이가 아니었다.
그때는 인스타 카드에만 적용했는데, 원래 그 구조는 웹 기사에서 온 것이다.

인터뷰로 가면 세 가지가 해결된다.

1. **편집자 해석이 줄어든다.** "그레이쥬스가 의도한 유머다"라고 내가 쓰는 대신, 만든 사람이 직접 말한다
2. **소제목 고민이 사라진다.** 질문이 구조를 만든다. 앞서 두 번 고쳤던 소제목 문제가 없어진다
3. **잉크 지표를 자동으로 통과한다.** 사람이 실제로 한 말은 불규칙하다. 그게 지표 1, 2, 5, 7, 8을 한 번에 만족시킨다

다만 조건이 하나 있다. **정리하지 않은 말을 받아 와야 한다.** 다듬은 답변을 받으면 인터뷰의 장점이 전부 사라진다.

## 2. 기사 구조

| 부분 | 분량 | 내용 |
|---|---|---|
| 제목 · 부제 | | 제품명을 제목에 쓰지 않는다 |
| 리드 | 15% | 에디터 서술 3~4문단. 물건을 묘사하고 질문을 세운다 |
| Q&A | 70% | 질문 8개에서 10개 |
| 제품 정보 | 10% | 소재, 치수, 가격, 판매처 |
| 크레딧 | 5% | Interviewee / Interviewer / Edit / Photo |

### 표기 방식

레퍼런스와 같이 간다.

```
Q.        질문은 한 문장. 길어도 두 문장.

그레이쥬스  답변. 구어체 존댓말. 200자에서 250자.
```

### 5단계와의 관계

인터뷰에서는 5단계가 질문 안에 흡수된다. 소제목을 따로 달지 않는다.
다만 검수할 때는 다섯 단계가 다 들어갔는지 확인한다.

| 단계 | 담당 질문 번호 |
|---|---|
| 제작배경 | 1, 2, 3 |
| 소재 | 7, 8 |
| DDP·서울 연관성 | 6, 10 |
| 제품특징 | 9 |
| 제작자 | 4, 11, 12 |

## 3. 질문지

### 먼저 알려 드릴 것

인터뷰 전에 그레이쥬스에게 이 문장을 보낸다.

> 답변은 정리하지 않으셔도 됩니다. 말씀하신 그대로 싣습니다.
> 생각나는 대로 길게 말씀해 주시면 저희가 고르겠습니다.

### 본 질문 12개

**시리즈와 시작**

1. 도시 채집가방이라는 이름이 먼저였나요, 장바구니라는 형태가 먼저였나요?
2. 첫 번째 도시가 함창이었습니다. 왜 함창이었나요?
3. 두 번째가 서울인데, 서울은 이미 너무 많이 다뤄진 도시잖아요. 부담은 없으셨어요?

**캐릭터**

4. 쿠:르릉은 어디서 왔나요? 이름부터 궁금합니다.
5. 외계인이 서울의 기념품을 빼앗아 가는 설정인데, 정작 이 가방은 기념품으로 팔립니다. 의도하신 건가요?
6. 만화 제목이 THE SEOUL ABERRATION이고 부제가 D.D.P SEOUL, ATYPICAL EVENING입니다. 왜 DDP가 배경이 되었나요?

**소재와 제작**

7. 타포린을 두 편 연속 쓰셨습니다. 이유가 있나요?
8. 타포린으로 만들 때 제일 어려운 건 뭔가요?
9. 파우치를 가방 안이 아니라 밖에 붙이신 이유는요?
10. 서울색 세 가지를 쓰셨는데, 색은 어떻게 고르셨어요?

**사람과 다음**

11. 이 가방을 어떤 사람이 들었으면 좋겠어요?
12. 다음 도시는 정해졌나요?

### 우선순위

시간이 짧으면 이 다섯 개만 한다. **4, 5, 6, 8, 11**

4번과 5번은 이 제품에만 있는 이야기다. 8번은 다른 인터뷰에서 잘 안 나오는 답이 나온다.
11번은 마지막 질문으로 두면 답이 길어진다. 기사 마무리로 쓰기 좋다.

### 같이 확인할 것

기사 질문은 아니지만 이 자리에서 정리한다.

- 소개문의 "시골 소품샵 키링의 이야기가 전개되는데" 대목. 1편 설명이 섞인 것인지
- 타이벡을 환경 관련 표현으로 쓰실 생각인지. 쓴다면 근거를 무엇으로 잡을지
- 가방 무게 (g)
- 판매 색상 옵션
- 1편 정식 제품명이 함창 채집가방이 맞는지
- 만화 영문 카피 전문 표기와 인용 승인
- 인스타그램 계정, 설립 연도

## 5. 답변을 받은 뒤 할 일 (잉크)

인터뷰 기사에서 편집자가 손대는 범위를 미리 정해 둔다.

**손대도 되는 것**
- 명백한 말실수, 중복된 접속사
- 질문과 무관한 곁가지 한 덩어리 통째로 삭제
- 답변 순서 바꾸기. 기사 흐름상 필요하면

**손대면 안 되는 것**
- 말버릇. "그니까", "뭐랄까", "약간"
- 흐려진 말끝. "...그랬던 것 같아요"
- 문법이 어긋난 문장. 말로는 자연스러우면 그대로 둔다
- 짧은 답변을 늘리는 것. 짧으면 짧은 대로 싣는다

**절대 안 되는 것**
- 하지 않은 말을 넣는 것
- 두 답변을 합쳐서 한 답변으로 만드는 것
- 답변에 없는 정보를 답변 안에 끼워 넣는 것. 그건 편집자 문장으로 따로 쓴다

## 6. 기존 원고와의 관계

에세이형 전문은 이미 완성되어 있다. 인터뷰 기사는 그것을 대체하는 것이 아니라 다른 물건이다.

| | 에세이형 전문 | 인터뷰 기사 |
|---|---|---|
| 화자 | 편집자 | 만든 사람 |
| 필요한 것 | 제품 자료 | 실제 인터뷰 |
| 강점 | 구조와 해석 | 신뢰와 목소리 |
| 상태 | 9.71, 잉크 통과 | 인터뷰 대기 |

**둘 다 쓸 수 있다.** 인터뷰가 성사되면 인터뷰를 웹 본편으로 올리고, 에세이형 전문은 짧게 줄여 제품 상세 설명으로 돌린다. 인터뷰가 어려우면 지금 전문을 그대로 쓴다.

인스타 카드 8장은 어느 쪽이든 그대로 간다. 인터뷰가 들어오면 카드 3번과 6번을 답변 인용으로 바꾼다.
