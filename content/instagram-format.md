# 채널 분배와 인스타그램 포맷

**레퍼런스**: edit.dept × rawpress.co 「로컬의 맨얼굴을 기록하다」 게시물 (실물 확인)

---

## 1. 레퍼런스 해부

### 카드 구성 (확인된 5장 이상)

| 장 | 형식 | 내용 |
|---|---|---|
| 1 | 제품 사진 + 큰 한글 제목 | "로컬의 맨얼굴을 기록하다" / 하단에 브랜드명 "로우프레스" |
| 2 | 형광 연두 단색 + 텍스트만 | 브랜드 소개문 8행. 하단 양쪽에 EditDept · 로우프레스 로고 |
| 3 | 흰 배경 + Q&A | `Q.` 라벨과 `로우프레스` 라벨을 붙인 문답 |
| 4 | 제품 사진 | 책을 쌓아 올린 컷 |
| 5 | 내지 스프레드 사진 + Q&A | 제품 안이 보이는 컷과 문답을 한 장에 |

핵심은 형식이 아니라 **주력 문체가 Q&A라는 점**이다. 에세이가 아니다.
질문 하나에 답 한 단락. 답변 어투는 구어체 존댓말이다. "~예요", "~거든요", "~잖아요".

### 캡션 구조

1. `[대괄호 제목]`
2. 큰따옴표로 감싼 인용 3단락. 2번 카드와 같은 내용이다
3. 🔔 기간 안내 한 문장
4. 🔵 "인터뷰 전문은 프로필 링크 내 웹사이트에서 볼 수 있습니다"
5. `—` 구분선
6. 행사 정보 (제목, 슬로건, 주최, 협력)
7. ✳ 기간, 장소
8. `—` 구분선
9. 크레딧 (Interviewee / Interviewer / Edit)

### 실측 글자 수

| 자리 | 글자 수 |
|---|---|
| 카드 1 제목 | 12자 (한 행) |
| 카드 2 텍스트 | 약 230자 / 8행 / 1행 25자 내외 |
| Q | 50~80자 |
| A | 200~250자 |
| 캡션 인용부 | 약 230자 |
| 캡션 전체 | 약 600자 (정보 블록 포함) |

## 2. 결론: 페이지와 인스타를 둘 다 만든다

줄일지 페이지로 만들지를 고민할 문제가 아니다. 레퍼런스는 둘을 이미 나눠 쓰고 있다.

| | 웹 페이지 | 인스타그램 |
|---|---|---|
| 역할 | 전문 보관, 검색 유입 | 발견, 저장, 공유 |
| 분량 | 5단계 전부, 2000~3000자 | 카드 8장, 총 1200자 |
| 문체 | 산문 + 스펙 블록 | Q&A 구어체 |
| 스펙 | 표로 전부 | 숫자 5개 이내 |
| 목표 행동 | 구매 | 저장, 그리고 링크 클릭 |

인스타에서 다 말하려 하면 저장이 줄고, 인스타에서 아무것도 안 말하면 클릭이 안 나온다.
**카드에서 ①②를 보여주고, ③④⑤는 웹으로 보낸다.**

## 3. 5단계를 카드로 옮기기

앞서 골드가 붙인 다섯 개 이름을 그대로 질문으로 바꾼다. 질문이 곧 카드 한 장이다.

| 단계 | 카드에 들어갈 질문 |
|---|---|
| ① 왜 만들었냐면 | "이건 왜 만들게 되셨어요?" |
| ② 뭘로 만들었냐면 | "소재가 좀 특이한데, 뭘로 만든 거예요?" |
| ③ 서울이 여기 있다 | "이 디자인이 서울에서 왔다고 들었어요. 어디서 가져온 거예요?" |
| ④ 써보면 이렇다 | 질문 없음. 숫자 카드로 |
| ⑤ 만든 사람 | "어떤 분이 만드셨어요?" |

③은 출처를 못 대면 카드를 통째로 뺀다. 앞 회차에서 정한 규칙과 같다.

### 카드 8장 구성안

| 장 | 형식 | 내용 | 글자 수 |
|---|---|---|---|
| 1 | 제품 사진 + 제목 | 한글 제목 1행, 하단에 브랜드명 | 제목 12~16자 |
| 2 | 단색 + 텍스트 | 제품이 무엇인지 한 덩어리로 | 180~230자 |
| 3 | 흰 배경 Q&A | ① 왜 만들었냐면 | Q 50자 + A 220자 |
| 4 | 제품 사진 | 디테일 컷. 텍스트 없음 | 0 |
| 5 | 흰 배경 Q&A | ② 뭘로 만들었냐면 | Q 50자 + A 220자 |
| 6 | 단색 + 텍스트 | ③ 서울이 여기 있다 | 120~150자 |
| 7 | 스펙 카드 | 치수, 무게, 용량, 가격, 개체차 | 항목 5개 이내 |
| 8 | 제작자 + 안내 | 이름, 계정, 구매 장소 | 100자 |

사진 카드와 텍스트 카드를 번갈아 놓는다. 텍스트 카드가 두 장 연속이면 이탈한다.
하단 양쪽 로고는 8장 전부에 고정한다.

### 캡션 템플릿

```
[제목 12~16자]

"[카드 2의 텍스트를 그대로. 200자 내외]"

🔔 [재고 또는 기간 안내 한 문장]

🔵 제품 이야기 전문은 프로필 링크 내 웹사이트에서 볼 수 있습니다.

—

[제품명]
[브랜드명 또는 스튜디오명]
판매 DDP 디자인스토어 [층·매대]

✳ 가격 [n]원
✳ [온라인 판매 여부]

—

Interviewee [디자이너] @[계정]
Interviewer [인터뷰어]
Edit [에디터]
Photo [촬영]
```

**주의**: 인스타는 캡션을 약 125자에서 자른다.
`[제목]`과 인용문 첫 문장 안에 승부가 있다. 정보 블록은 아무도 펼쳐 보지 않는다고 가정하고 쓴다.

## 4. 페르소나 검토

**라이트 (편집)**
채널 분배는 내 담당이다. 위 표대로 간다. 다만 하나 지운다.
카드 2와 캡션 인용부가 같은 내용인데, 레퍼런스가 그렇게 했으니 그대로 둔다. 이건 중복이 아니라 캐러셀을 안 넘기는 독자용 보험이다.
대신 **카드 7의 가격과 캡션의 가격은 중복이다.** 캡션에서 지운다. 스펙은 카드에 몰고, 캡션은 장소와 계정만 남긴다.

**골드 (독자)**
1장에서 넘길지 말지가 정해진다. 제품 사진에 제목을 얹는 건 맞다. 다만 레퍼런스의 제목은 "로컬의 맨얼굴을 기록하다"처럼 **제품 이름이 아니다.** 제품 이름을 제목으로 쓰면 광고로 보이고 넘기지 않는다.
카드 7 숫자 카드는 반드시 넣어라. 저장 버튼을 누르는 장이 이 장이다. 나중에 사려고 저장한다.
판정: 이 구성이면 **저장한다. 링크 누른다.** 사는 건 스펙 카드를 보고 정한다.

**실버 (전달)**
Q&A로 바꾼 것이 이 회차의 가장 큰 개선이다. 산문은 소리 내어 읽으면 카드에서 길어지는데, 질문과 답은 말이라서 짧아도 완결된다.
다만 답변에서 한 가지를 지킨다. **A 한 덩어리에 판단 하나만 담는다.** 250자 안에 두 가지를 말하면 카드에서 둘 다 안 읽힌다.
강의 비유를 하나 낸다. 슬라이드 한 장에 메시지 하나다. 두 개를 넣으면 청중이 어느 쪽을 적어야 하는지 몰라서 둘 다 안 적는다.

**레드 (비판)**
1. 팩트. 이 구성안 자체에는 검증할 팩트가 없다. 다만 캡션 정보 블록은 오기가 바로 문의로 돌아오는 자리다. 가격, 층, 온라인 판매 여부는 게시 직전에 매장과 한 번 더 맞춘다.
2. 정합성. "인스타에서 ③④⑤를 웹으로 보낸다"고 하면서 카드 6, 7에 ③④를 넣었다. 말과 구성이 어긋난다.
   대안: 문장을 고친다. **카드에는 ③④의 결론만 넣고, 근거와 전체 스펙은 웹에 둔다.** ③은 출처 한 줄, ④는 숫자 다섯 개까지다.
3. 시장. 카드 8장은 요즘 기준으로 길다. 5장에서 이탈이 크다.
   대안: 8장을 만들되 **순서를 다시 짠다.** 스펙 카드를 7장에서 4장으로 올린다. 사려는 사람은 숫자를 빨리 보고, 이야기가 궁금한 사람은 계속 넘긴다. 이야기를 먼저 깔고 숫자를 뒤에 두는 건 인쇄물 순서다.

**퍼플 (서사)**
레드의 순서 변경에 동의하지 않는다. 스펙을 4장에 올리면 3번 가이드 단계가 사라진다. 공감을 보이기 전에 사양을 내미는 것은 가이드가 아니라 판매원이다.
절충안을 낸다. **카드 4를 사진 대신 "숫자 미리보기" 한 장으로 바꾼다.** 치수와 가격만 큰 글씨로 두 줄. 전체 스펙은 7장에 그대로 둔다. 급한 사람은 4장에서 멈추고, 나머지는 계속 간다.
6번과 7번 짝은 8장에 둔다. 실패는 소량 생산이고, 성공은 친구의 질문이다. 카드 마지막 문장을 이렇게 쓴다. "집에 온 친구가 어디서 샀냐고 물어보면, 이 계정을 보여주세요."

**블랙 판정**
- 라이트의 가격 중복 제거: **수용**
- 골드의 "제품명을 제목으로 쓰지 말 것": **수용**. 치명에 해당한다
- 실버의 "A 하나에 판단 하나": **수용**
- 레드의 정합성 지적: **수용**. 문장을 고쳤다
- 레드의 스펙 카드 전진: **기각**. 퍼플의 절충안을 택한다. 숫자를 앞세우면 이 계정의 성격이 바뀐다. 카탈로그 계정과 매거진 계정은 팔로워가 다르고, 우리는 후자로 운영하고 있다
- 퍼플의 카드 4 변경: **수용**
- 퍼플의 마지막 문장: **조건부 수용**. 취지는 받고 문장은 다시 쓴다. "보여주세요"는 부탁이다. 명령형 하나만 쓰기로 한 원칙에 따라 구매 유도 문장 한 개만 남긴다

### 확정 카드 순서

1 표지 (제품 사진 + 제목, 제품명 아님)
2 단색 텍스트, 제품이 무엇인지
3 Q&A ① 왜 만들었냐면
4 숫자 미리보기 (치수, 가격 두 줄)
5 제품 사진 디테일
6 Q&A ② 뭘로 만들었냐면
7 단색 텍스트 ③ 서울이 여기 있다 (출처 없으면 삭제)
8 스펙 전체 + 제작자 + 구매 유도 한 문장

## 5. 다음 단계

소재가 들어오면 이 구성으로 카드 8장 문안과 캡션을 한 번에 쓴다.
웹 페이지 원고는 같은 소재로 따로 쓰되, 카드에서 잘라낸 근거와 전체 스펙이 그쪽에 들어간다.
