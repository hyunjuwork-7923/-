## 현재 상태

**서울 채집가방** · 그레이쥬스 · 36,000원

| 원고 | 평균 | 잉크 |
|---|---|---|
| 웹 전문 | 9.71 | 통과 |
| 티저 A안 이야기형 | 9.71 | 통과 |
| 티저 B안 물건형 | 9.71 | 통과 |

게시 전 남은 일은 원고가 아니라 확인이다. 목록은 최종 원고 파일 7장과 8장에 있다.

**게시 순서**: A안을 먼저 올리고 3일에서 5일 뒤 B안. A안이 만화로 사람을 데려오고, B안이 망설이는 사람을 정리한다.

---

## 새 제품 원고를 만드는 순서

1. `product-intake.md`로 소재를 받는다
2. 소재를 보고 스토리형인지 기능형인지 판정한다. 디자이너 발언이 없으면 스토리형은 만들지 않는다
3. 레드가 집필 전에 팩트를 검증한다
4. 블랙이 전문 초고를 쓴다
5. 여섯 명이 채점하고, 블랙이 수용하거나 기각한다
6. 블랙이 재집필한다
7. 잉크가 감사한다. 보류면 점수와 무관하게 게시하지 않는다
8. 통과하면 인스타 티저 2안을 만든다
9. 입력란을 채우고 확인 목록을 지운 뒤 게시한다

## 원칙 두 개

**없는 사실을 만들지 않는다.** 확인되지 않은 수치, 하지 않은 말, 없는 경험은 쓰지 않는다. 자료가 비면 그 단계를 빼고 쓴다.

**DDP·서울 연관성은 출처를 대지 못하면 통째로 뺀다.** 억지 연관성 하나가 나머지 항목의 신뢰를 같이 무너뜨린다.
